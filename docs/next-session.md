- **The Pi's windows:** `config/labwc-rc.xml` is generated by `tools/make_labwc_rules.py` (rules come from `multi.rules_xml`). Copy it to `~/.config/labwc/rc.xml` and reload with `kill -HUP $(pgrep -x labwc)` (`labwc --reconfigure` fails: no LABWC_PID). - **Notices:** `tv_note()` draws coloured text straight on the picture (mpv `expand-properties show-text` with `${osd-ass-cc/0}` ASS styling), on every window when several streams are up. Used for the heat warning (warns at 78 C, lowers pictures at 82 C) and, for one full-screen stream, volume and paused (setting `notice_style`: coloured or classic). - **Watch on phone / this computer:** a full-screen player (`#watchcard`), a large panel in the desktop layout, bundled `app/vendor/hls.min.js` for Chrome/Edge/Firefox, closes itself when the stream ends.
- **Sound:** WirePlumber remembers a stream's mute and put it back on every new mpv; `mpvipc.set_mute(sock, False)` mutes then unmutes. The mute button is optimistic and sends `mute_on` / `mute_off`.

## Gotchas learned
- **Backslashes get mangled** in heredocs and edits (`\\n` becomes a real newline, `\1c` becomes a control character). For ASS and JS strings build with `chr(92)` or write the script to a file with the Write tool. `tests/test_ui_syntax.py` (index.html and tv.html) and the ASS tests catch it. Also: Git Bash's `/tmp` is not Python's `/tmp` on this PC; use the Write tool for files that both need.
- Chrome tool: "chrome-extension of a different extension" errors mean open a fresh tab; remote tabs left open across a deploy run old code. `?v=N` busts the cache.
- App target names: `living` is the Pi (it is on the BEDROOM TV), `bedroom` is the Chromecast. The Roku "Living room" is .141 (the roommate's: ask first); the bedroom Roku .142 is free to test on.
- mpv over IPC does not expand `${...}` unless the command starts with `expand-properties`.
- Tests leak state: clear `_swapping` and similar globals in new tests.
- To see the real TV: `grim -c /tmp/x.png` on the Pi with `XDG_RUNTIME_DIR=/run/user/1000 WAYLAND_DISPLAY=wayland-0`.
- The Pi has 1.8 GB RAM (about 1 GB free) and runs 72-76 C with a 1080p60 stream. The browser costs about 335 MB while the launcher is up and nothing while a stream plays.

## Gotchas hit this session (save time)
- The edit tooling collapses doubled backslashes inside heredocs: ASS strings (`\an7`, `\pos`, `\b1`) and `’` got corrupted into control characters. Write patch scripts with the Write tool into the scratchpad and run them, or build backslashes with `chr(92)`. Check for stray control chars (`ord(c) < 32`).
- A trailing `//` comment appended to a one-line JS statement swallowed the rest of the line and blanked the whole page; `tests/test_ui_syntax.py` catches it (it runs `node --check`). Always run the full suite BEFORE pushing: `python -m unittest discover -s tests > /tmp/t.log; tail -3 /tmp/t.log` and only commit on "OK" (never chain commit after `| tail`).
- The stub server (`python tests/stub_server.py 8799`) serves the page read at start: restart it after edits, and load with a new query string (`/?v=n`) so Chrome reloads. Claude-in-Chrome can disconnect; the stub has no `/api/detect`, `/api/qr`, admin routes: mock `fetch` in the page.
- Tests that mock `mpvipc.send` can be polluted by leaked daemon threads of other tests: assert with `any`/`in`, not first/last or exact counts.
- mpv reports a `duration` for a live HLS stream (the cache length): never use "duration is None" to decide live; use `is_channel(url)`.
- Settings opened straight from `#/settings` ran `loadShell` before the TV list existed (cards hidden): `loadTargets` now re-runs it for the settings view.
- `/api/setup` answers non-admins with `{needed: false}` only: the client must not treat missing fields as "fresh install".
- Pi: `/dev/input/event0` (vc4-hdmi-0) and `event2` are the CEC key devices; `cec-ctl --monitor-all` needs root; the Pi's CEC announcement now has extra RC features until the next container restart.
